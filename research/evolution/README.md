# AUREON Ω PRIME Evolution Engine

This layer converts research output into a controlled evidence loop.

## Invariants
- Gold/XAUUSD only while BTC is paused.
- Historical controls, dataset hashes and untouched holdouts are immutable evidence.
- ASTRA/NVIDIA may propose hypotheses but cannot alter measured metrics or promotion gates.
- At most two causal variables may change per controlled mutation.
- No candidate may reach demo-forward before native MT5 real-tick verification.
- Real-money execution is never authorized by this engine.

## Loop
Observe → diagnose → hypothesis → challenger → development screen → validation → holdout → neighbor stability → walk-forward → cost/slippage stress → Monte Carlo → MT5 real ticks → champion comparison.

The deterministic engine writes a hash-linked verdict and append-only JSONL evidence ledger. Failed candidates receive machine-readable failure classes so later research can target the cause instead of blindly optimizing headline profit.
